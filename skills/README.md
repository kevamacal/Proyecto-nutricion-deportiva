# Developer Skills Framework (`skills/`)

This directory contains baseline skill templates and domain guidelines used by AI coding agents when working on the **Sports Nutrition & Athletic Performance Platform**.

## Skills Index

- **[`boilerplate_skill.md`](./boilerplate_skill.md)**: Starter template for creating modular developer skills.
- **[`sports_nutrition_domain_skill.md`](./sports_nutrition_domain_skill.md)**: Domain verification rules for Mifflin-St Jeor BMR, TDEE, basketball/gym MET energy expenditures, and macronutrient allocations.

## How to Add New Developer Skills

1. Copy [`boilerplate_skill.md`](./boilerplate_skill.md) to a new file in `skills/<skill_name>.md`.
2. Define the skill purpose, inputs, deterministic execution steps, and verification commands.
3. Update this `README.md` index.
